Durante este curso aprendí que la tecnología puede fortalecer la participación ciudadana y la organización comunitaria. Comprendí la importancia de desarrollar herramientas útiles para resolver problemas reales. Aprendí a utilizar Git y GitHub para organizar proyectos, Node.js y Express para crear aplicaciones y bases de datos para almacenar información. También entendí la importancia de proteger los datos personales y usar la tecnología de manera responsable. El proyecto Petición en 3 Clics demuestra cómo una aplicación puede ayudar a registrar apoyos y generar documentos para una causa comunitaria. Estos conocimientos serán útiles para desarrollar soluciones con impacto social.
